- 🗄️ 3-layer MySQL architecture with `kpi_master` as single source of truth
- 🔐 SHA-256 duplicate detection + full upload audit trail
- 📊 Interactive dark-theme dashboard with donuts, gauges, funnels, treemaps & area trends
- ☁️ Deployed on Streamlit Cloud + Aiven-hosted MySQL
